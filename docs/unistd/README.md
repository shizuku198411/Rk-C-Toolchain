# rkc_unistd.h

`<rkc_unistd.h>` declares identity helpers installed by
`rkcstdlib --install`.

## Functions

| Function | Summary |
| --- | --- |
| [`getuid`](getuid.md) | Return the current user id |
| [`getgid`](getgid.md) | Return the current group id |

## Header

```c
#include <rkc_unistd.h>
```
